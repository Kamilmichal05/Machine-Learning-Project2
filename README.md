# ML2 — Jupyter project

A Python notebook workspace for data exploration and machine learning.

## Setup

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Start JupyterLab

```sh
source .venv/bin/activate
jupyter lab notebooks
```

Open `01_getting_started.ipynb` and run the cells. The example generates data locally and plots a linear regression fit.
